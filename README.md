# Nurkamol Tap

## How do I install these formulae?

`brew install nurkamol/tap/<formula>`

Or `brew tap nurkamol/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "nurkamol/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
